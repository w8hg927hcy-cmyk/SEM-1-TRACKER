# SEM1 OS — Engineering Semester 1 Tracker

## Update your existing GitHub Pages website
1. Download and extract `sem1-os-updated.zip`.
2. Open your existing GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload the new `index.html` and `README.md`, replacing the old versions.
5. Commit changes to the `main` branch. GitHub Pages will publish the update automatically after a short wait.

## What's new
- Subject stays open after adding, editing, or ticking a topic.
- Index-style table with numbered topic rows.
- Each subject can independently enable/disable Theory, Numericals, and Theorems columns.
- Progress is calculated only from enabled columns. Keep at least one column enabled per subject.
- Maths starts with Theorems enabled; PCE starts with Numericals disabled. You can change either.
- Improved high-contrast navy, white, and amber design.
- Existing `sem1os_v1` browser data is migrated automatically when the updated site is opened.

## Data
Data remains saved in the browser on each device. Export a backup before clearing browser data or changing devices. GitHub Pages does not sync progress between devices.
